This page needs the HishabAI server

You opened index.html directly as a file, so it has no data and nothing works. The page only works when the Python server sends it.

In the terminal, inside the project folder, run:

.venv\Scripts\activate
python -m app.server

Then open http://127.0.0.1:8000 in your browser.
